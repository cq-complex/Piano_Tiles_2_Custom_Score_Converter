# 钢琴块2自制谱 JSON 生成器

运行环境：Python 3.10 或更新版本。

```powershell
python -m pip install -r requirements.txt
python main.py
```

在界面中选择 MIDI 文件、主旋律音轨、可选的伴奏音轨、基础拍长和移调值。移调值为整数半音，`1` 表示升一个半音（如 `e` 到 `f`），`-1` 表示降一个半音（如 `e` 到 `#d`）；主旋律与伴奏都会移调。点击“预览 JSON”可在程序内查看完整内容；点击“生成 JSON”选择保存位置。生成的 JSON 使用示例文件的 `baseBpm`、`musics`、`audition` 结构，整个文件只有一行。

点击“导入 MIDI / MusicXML / JSON”可以打开已有谱面。MusicXML 支持 `.musicxml`、`.xml` 和压缩的 `.mxl`；不同声部谱表可分别作为主旋律或伴奏，转换沿用 MIDI 的设置和分段流程。MusicXML 按文件中的乐谱顺序读取，不展开反复记号。

导入已有 JSON 会打开校正界面并保留原段数与各段参数。至少需要一段；段数不等于三时自动识别为竞技场谱面，仍可编辑、试听和导出。竞技场的段落可以省略 BPM。试听时优先参考有效的 `baseBpm`，其次用首个已填写的段落 BPM；两者都没有时用 120。导出保留缺省字段。三段分割与三段梯度增速不适用于竞技场谱面。MIDI 和 MusicXML 转换固定生成三段普通谱面。橙色是异常短音符；红色是语法错误或违反特殊方块硬性规则的片段。选中条目，在片段输入框修正后点击“应用修改并重新检查”，也可以撤销。语法错误可能无法恢复原时长，修复时请核对伴奏对齐。若 JSON 文件本身缺括号、逗号等，可在导入时先修正红色位置。红色错误修复后才能导出，导出仍为单行 JSON。

主界面的“编辑 / 试听歌单片段”用于设置串烧歌单截取范围。界面从第 1 段、第 1 项开始编号，导出为从 0 开始的 `audition.start` 和 `audition.end`；例如 `[0,0]` 到 `[0,16]` 包含第 1 段的前 17 项。两端都包含，允许跨段或只选一项。特殊方块 `x<...>` 内的音符逐项计数，和弦与休止符各占一项。可以先用系统钢琴试听当前选择（包含伴奏），再点“应用到 JSON”保存到当前谱面。后续校正音符时，程序会随替换调整已设定的歌单坐标。

移调输入框右侧实时显示推测调式。程序使用整份 MIDI 的非鼓轨音符，按音符时长统计音高类别并拟合十二种大调音阶；移调时同步更新，例如 C 大调升两个半音显示 D 大调。不使用单一主音轨或 MIDI 自带调号作为唯一依据。候选接近时显示“不确定”，变化音较多时显示“不明确”。这是大调音阶拟合，不能仅凭音阶区分关系小调或可靠判断中途转调。

伴奏选择框支持“无”、单个音轨及“其余全部音轨”。超过两条音轨时默认选择其余全部音轨：输出的每段 `scores[0]` 始终为所选主音轨，其余原始音轨按序号顺序分别排列在后，不混成一条、不重复主音轨。所有轨道使用相同时间原点、相同分割点和相同总时长，保留各自休止符，`instruments`、`alternatives` 数量随轨道数同步扩展；继续沿用程序的钢琴音色。对齐评分、自动节拍检测、伴奏触发的休止符检查及片段试听会使用所选的全部伴奏。

勾选主音轨旁的“合并全部音轨”后，主旋律与伴奏选择框禁用，整份 MIDI 的所有音轨合成一个主音轨，每个谱段仅输出一个 `scores` 项。程序按量化后的原始起音位置对齐音符，仅在同一时刻新起音的音符写成和弦；持续中的音符不复制到后续方块，音符结束也不会触发新方块。同一时刻的同音起音去重，不同时刻的同音起音保持独立。无声间隔保留休止符。移调、节拍缩放、三段分割、校正与试听均使用合并后的谱面；对齐评分和自动节拍检测使用全部原始音轨。

例如 `a1[L],d1[L],f1[L],a1[L]` 与 `d[J]` 合并为 `(d.a1)[L],d1[L],f1[L],a1[L]`，低音 d 只在开头起音一次。合并块长度按本次新起音的时长计算，并在下一个新起音处截分，不重播早先的长音；单轨无法保留各声部独立的持续时长，需要完整保留时应使用分轨模式。取消勾选后恢复原主音轨及伴奏选择；合并和分轨模式的手工校正结果分别保存在内存中。

点击“预览 / 校正非正常音符”打开校正窗口：

1. 上方列出各段主旋律中的全部问题片段，包括短于当前最小正常长度的普通音符、被伴奏发声触发为黑块的短休止符，以及不符合规则的特殊方块。连续异常短音符与短休止符归为一个片段；两条音轨同时休止时不报错，伴奏中的短音符本身不列为问题。判断按时值累计的时间区间进行，涵盖任意伴奏音轨、持续音以及部分重叠，恰好在边界相接不算重叠。例如 baseBeats=0.5 时主旋律 V 对应伴奏 M，会被列为问题；两条音轨都是 V 则不报错。
2. JSON 中用橙色高亮问题。点击列表可定位，蓝色标出当前操作范围。段号与音符序号从 1 开始，特殊方块整体算一个音符。需要纳入相邻音符时，修改起止序号并点击“载入范围”。
3. 选择类型后点击“套用方块”，也可直接在片段框中编辑音符、长度及方块语法。点击“应用修改并重新检查”提交，支持逐步撤销。
4. “导出修改后的 JSON”保存当前结果。关闭窗口后，已应用修改仍会用于主窗口的预览和生成；未点击应用的输入不会保存。不同转换设置的校正结果分别保存在内存中，重新选择 MIDI 或退出程序会清空。需要保留成果时请导出 JSON。

“建议更改”面板为每个问题片段提供按推荐顺序排列的候选。点击候选会在片段框中预览修改文本，并在 JSON 中高亮实际范围，不会立即提交；“@ 琶音（含后一音）”会将选区扩大一个音符。可先试听编辑片段，再点击“应用此建议”逐个提交，或继续手动调整并使用原有的“应用修改”按钮。

建议规则如下：

| 特征 | 建议 |
| --- | --- |
| 单个短音或多个等长细分短音，音高连续同向推进，加入后一长音后组合长度的最小分量不短于当前最小正常音符 | @ 琶音，纳入后一音；不限制组合字母数量，如 0.25 下 O+KLNO=KLM，最小分量 M 合法 |
| 恰好两个短音，总长度为最小正常长度 | 5 双黑，包括 NO+O 等不等长组合 |
| 偶数个等长半格音符 | 双黑块阵，或 3 狂戳 |
| 奇数个等长半格音符（至少三个） | 3 狂戳 |
| 至少三个音，每个时长与均值相差不超过 1P，总长度为正常长度整数倍 | ~ 连音，适合连音取整造成的近似等长音符 |
| 多个时长均小于半格的细分短音 | 7 长滑块或 8 折叠滑块，不纳入后一音 |
| 特征不明确、总长度已达到最小正常长度的普通片段 | 6 长条作为通用备选 |
| 总长度仍不足最小正常长度 | 分别尝试并入后一音、前一音，达到最小正常长度后才建议 6 长条 |

这些是可人工选择的启发式建议，并不保证还原作者意图。同一片段可有多个候选，所有候选均检查语法、方块硬性规则和替换前后总时长；已有违规特殊方块不自动嵌套包装，需要手工调整。

不足最小正常长度的片段不会直接建议或允许应用 `6<...>`。邻音扩展建议会明确标注“并入前一音”或“并入后一音”，预览高亮和起止序号同步扩大；没有合适相邻音符时保留待处理，并提示扩大范围或调整分段。旧版本生成的过短长条会重新标为异常；可在建议中展开其内部音符，再与邻音合并，避免嵌套长条。批量应用遇到范围重叠的建议会跳过冲突项，保留未处理片段，不重复或丢失音符。

短音符或短和弦也可吸收紧随其后的休止符：例如 baseBeats=0.25 时，`b1[NOP],Y` 会提供“延长音符”为 `b1[M]` 和“长条”为 `6<b1[NOP],Y>` 两种候选。必要时连续纳入多个后续休止符，直到总长度达到最小正常长度；延长方案仅保留一次原起音，通用长条方案保留内部休止写法，两种方案都保留原总时长和其他轨道。休止符已因伴奏触发而与短音符列在同一问题片段时，也能识别。基础拍长为 0.5 时，上例合计 M 仍短于 L，因此不会提供这两个不合法方案。向前扩展的通用长条也允许纳入相邻休止符。

“一键应用所有首选建议”会先生成实际可应用的更改清单，并弹出确认窗口。窗口逐项列出段号、音符范围、方案、理由、原文和替换结果；长清单可以滚动查看，已忽略或范围冲突的项不列入。只有点击“确认应用全部更改”才提交，点击取消、按 Esc 或关闭确认窗口均不修改谱面。提交按反向顺序进行以避免音符序号偏移；尚未应用的草稿不参与批量操作。整次批量修改可一键撤销。“忽略当前片段”会保留原内容并仅排除在批量修改之外，列表以灰色和“已忽略（仅批量）”标注；仍可选择该片段手动应用建议或编辑。“取消当前忽略”和“取消全部忽略”可恢复批量处理。批量建议向邻音扩展时也不会覆盖被忽略片段。忽略状态按当前转换设置保存在内存中，关闭再打开校正窗口仍保留；重新选择 MIDI 或退出程序会清空。忽略标记不会写入导出的 JSON，被忽略的问题仍计入剩余问题数量。

校正窗口还支持手动“合并发音”。载入需要合并的音符范围（可扩大范围纳入结尾的长音符），在“合并发音”中选择 `@ 短时琶音`、`~ 均匀滑音` 或 `. 同时和弦`，点击“合并片段音符”。结果先显示在片段框，确认后点击“应用修改并重新检查”；已应用的操作可撤销，也可直接导出。

例如，使用 @ 可将 `#d2[O],#g2[O],c3[O],#d3[JKLMO]` 合并为 `(#d2@#g2@c3@#d3)[I]`；使用 ~ 可将 `#c3[NP],(#c3.#d3)[NO],(#c3.#d3)[NP]` 合并为 `(#c3~#c3.#d3~#c3.#d3)[L]`。

合并会保留音高的原始顺序、重复音及已有发音连接关系，不排序、不去重；长度为所有音符时值之和，并自动使用组合长度或重复 H。支持普通音符、和弦和单个包含多个音符的 `6<...>` 长条。用 `~` 合并时，内部连续休止符可写成一个无声位置 `mute`。合并保留总时长，但会按所选连接符改变内部发音方式，不保留每个原音符的独立起音时刻。此功能由用户手动选择，不自动把 MIDI 中分开的音符合并。

校正窗口支持片段试听（Windows）：

- 点击“试听原片段”播放当前段号及起止序号对应的已应用谱面。
- 载入范围并编辑后，点击“试听编辑片段”播放片段框中的草稿，无需先应用修改。草稿总时长须与原范围一致，试听不会修改谱面。
- “包含对应伴奏”可开关同一时段的伴奏，范围开始前已发声且持续到该范围的音符也会正确截取。
- 点击“停止”可立即停止；切换载入范围、应用修改、撤销、关闭窗口或播放结束后会停止播放并释放 MIDI 输出设备。再次试听会停止上一次播放。

试听直接在内存中生成 MIDI 时间轴，由独立后台线程按绝对时间向 Windows 默认 MIDI 输出发送全部消息，不依赖 MCI 的播放状态、时长报告或临时文件。只有全部事件发完、完整片段时长（包括尾部休止）经过，并保留约 0.35 秒尾音后才释放输出设备。界面显示已播时间和总时长；手动停止和关闭窗口可中断等待并关闭输出设备。重复的同一片段选择通知不会重新载入草稿或中断播放。输出错误会明确报告。

试听根据谱面音高、组合长度及当前谱段 BPM 生成 MIDI 事件，直接调用 Windows WinMM MIDI 输出，无需额外播放器或音源包。采用系统钢琴音色；休止符保留静默时长，特殊方块按内部音符顺序试听。`.` 表示同时发音，`~` 近似为均匀滑音，`@` 近似为开始最多 120 毫秒内的快速琶音，混合连接关系也支持。游戏特定音源、特殊方块玩法及精确发音效果不在系统 MIDI 试听中模拟。若系统 MIDI 输出不可用，界面会显示错误。

Windows MIDI 输出接口参考：[Microsoft MIDI 消息发送文档](https://learn.microsoft.com/en-us/windows/win32/multimedia/sending-individual-midi-messages)。

支持的特殊方块及检查规则：

| 类型 | 规则 |
| --- | --- |
| 3 狂戳 | 每个内部音符等长，且等于当前最小正常音符长度的一半 |
| 5 双黑 | 恰好两个内部音符，时长之和等于最小正常长度，允许如 MN+N、MNO+O |
| 6 长条 | 将内部音符合并为一个长条，总长度必须达到最小正常长度 |
| 7 长滑块 / 8 折叠滑块 | 内部每个音符严禁超过最小正常长度的两倍；建议不超过一半 |
| 9 伴奏块 | 对应时段有完整覆盖的伴奏，伴奏中每个音符恰好为最小正常长度 |
| 10 爆裂 | 后续每个音符为最小正常长度，后续时长之和严格等于首个主块时长的两倍 |

方块只在主旋律中应用，不修改伴奏。替换片段的时值按所有内部音符相加计算（爆裂块包括首个主块及后续音符），替换前后必须相等，以保留分段结构和伴奏对齐。无效语法和不符合方块硬性规则的修改会被拒绝，合法但仍为短音符的片段可先应用，再继续校正。导出允许保留待处理片段，成功提示中会显示剩余数量。

主窗口的“三段分割”支持两种模式：

两个分割点各可试听前 5 秒或后 5 秒，使用当前输出 BPM、主旋律和伴奏。试听时长向上取整到 1/32 拍，可以跨过另一个分割点，到曲首或曲尾时截短。可点击“停止试听”结束播放。

- **自动避开异常片段**：两个分割点两侧都必须紧邻正常长度的主旋律音符。优先在接近总时长 1/3、2/3 的完整音符边界分割；边界不足时，可以切开长音符，但截出的每一部分都必须达到最小正常长度。找不到两个合规分割点时会提示调整谱面或设置。
- **自选分割点**：输入缩放后的四分音符拍位置，首个音符为起点 0。点击“查看分段”可查看实际区间。分割点按 1/32 拍取整，取整后必须严格递增，并满足同样的主旋律音符要求。

分段对主旋律和伴奏同步生效，不丢失或重复时间。只修改基础拍长时保留已有自动分割点；如需根据新的最小正常长度重新规划，点击“重新自动规划”。建议先选择分割区间，再校正异常音符。不同分割区间的编辑结果分别保存在内存中，改变区间会从 MIDI 生成对应谱面，不会自动搬移其他区间设置下的手工修改；切回原设置可恢复已应用修改。

基础拍长通过整数指数 x 输入，值为 `0.5^x`。例如 x=1、0、-1、3 分别对应 0.5、1、2、0.125。修改指数只改变 JSON 的 `baseBeats` 数值，谱面音符、时长字母和分段均保持一致。

指数输入框右侧实时显示对应基础拍长；输入无效时会显示提示。

主界面实时显示“当前速度”，单位为块/s，按 `BPM / (60 × 基础拍长)` 计算，BPM 使用当前手动缩放或自动校正后的输出数值。基础拍长、节拍缩放和梯度增速变化时同步更新。速度按 2、5、8、10、13 块/s 分为六档，分别用不同颜色提示；速度达到或超过 13 块/s 时显示红字“警告：谱面滚动速度可能过快，难以游玩”。三段速度不同时逐段显示提示。未读取谱面或输入无效时隐藏提示。

基础拍长数值后还会显示“当前最小正常音符”：x=1、2、3、4 分别为 L、M、N、O；x=0、-1、-2 分别为 K、J、I；x≥5 显示所有音符均可正常显示；x≤-3 按 `H*(2^(-3-x))` 显示。

对于标注 BPM 与实际节拍不匹配的文件，点击“检测节拍”或勾选“自动校正节拍”。程序根据选中音轨的起音位置、起音间隔和音符时长寻找更规则的十六分音符网格，并显示建议 BPM、节拍缩放比例和对齐评分。校正同时缩放所有选中音轨的拍位置及输出 BPM，因此量化前的播放时长保持一致。预览和保存均使用当前校正结果。

自动校正默认关闭；关闭自动并将手动比例设为 1 可恢复原始节拍。程序仅在对齐评分明显提高时应用推测结果，优先选择接近原 BPM 的解释；搜索范围为原 BPM 的 0.5–2 倍且处于 40–240 BPM。少于 8 个有效起音或包含中途变速时不应用校正。节拍存在半速、倍速及三连音等歧义，自动检测无法保证还原作者原始 BPM。

自动结果不合适时，关闭“自动校正节拍”并输入“手动缩放比例”，支持任意有限正数。比例 = 目标 BPM / 原始 BPM。例如原始 120、目标 150，输入 1.25；目标 96 则输入 0.8。旁边实时显示输出 BPM。预览与保存同步缩放音符时值和 BPM，基础拍长不受影响。输入 1 可恢复原始节拍。自动模式开启时手动框禁用，防止叠加两次缩放。低评分且未找到可靠结果时，检测报告会显示原评分及最佳候选，并提示使用手动缩放。

手动比例输入时还会实时显示“当前对齐评分”和原始评分，修改比例或切换主旋律、伴奏音轨后立即更新，无需点击检测按钮。手动评分与自动检测使用相同的十六分音符网格及起音位置、起音间隔、音符时长权重；分数按取整前的数据计算。对变速 MIDI 使用积分后的拍位置评分。评分样本会缓存并限制数量，避免每次输入都重新分析整首 MIDI。无效比例或无音符时显示不可用提示，不沿用上一个分数。

程序将同一时刻开始的音符写成和弦，将空白时段写成休止符。音符起止位置固定按四分音符拍的 1/32（最小符号 P）取整对齐；L 固定对应半拍，不受基础拍长设置影响。单个音符的长度以字母叠加表示，例如 `g[MN]`、`f[HHH]`，不会将 MIDI 中分开的同音音符合并。每条音轨的总时长一致。谱面按自动规划或自选区间分为三个 `music` 段，必要时在边界截分跨段音符。程序在 Windows 上启用逐显示器 DPI 感知，界面随显示器 DPI 调整。程序使用钢琴音色和 MIDI 的初始 BPM。MIDI 中途的速度变化会按拍位置保留音符间距，但不会写成分段变速。移调后超出钢琴音库 A0–C8 的音符会报错。

在校正界面，疑似因量化而出现微小时值差的三连音会标为紫色，即使每个音都已达到最小正常长度。可用 `~` 合并，总时长不变。批量确认窗口中可逐条选方案、编辑替换内容，或选择“本次跳过”“忽略”；忽略的片段之后仍可手动应用。所选更改有冲突时，需要先调整方案或跳过其中一条。

副音轨中识别出的 `~` 连音和 `@` 琶音也标为紫色。校正界面可按轨号试听、编辑、批量应用或忽略这些发音建议；第 1 轨为主旋律。普通短伴奏音符不会标橙，副音轨的方块类型标记不会当作玩法错误。

MusicXML 导入会读取 `arpeggiate`（琶音）和 `tuplet`（连音起止），并识别可明确分组的 `time-modification` 连音。可完整表达的琶音按标注方向输出为 `@`，等时值的连续连音合并为 `~`，主旋律和伴奏都适用。分割点不会切开已合并的组；有休止、混合时值或与其他声部重叠而无法原样合并的组保留原音符。

导入 JSON 后会根据各段音高推测调式，调整移调值会同步更新导入谱面。支持并保留 `C-1[M]{3}` 等背景动效后缀，以及 `mute`、`empty`、`chuanshao`。前两者等同休止；`chuanshao` 的游戏风铃音在系统钢琴试听中留空。含休止的连音可写成 `(a~mute~a)[K]`。

- **小节分隔**：MusicXML 使用文件中的小节位置；MIDI 只在文件包含拍号时推算小节线。开启时用 `;` 标记小节线，自动三段规划优先选合规的小节边界。检测到跨小节音符会默认关闭，开启前会确认。开启后跨线音符保持完整，该音轨跳过被跨越的小节线。
- **3段梯度增速**：开启后输入 BPM 公差。三段分别为基础 BPM、基础 BPM 加一个公差、基础 BPM 加两个公差。试听使用各段 BPM，基础拍长和音符时值保持原样。导出提示列出每段的 BPM 与基础拍长，便于填入 APK 的 CSV。

校正器的“解散所有音符组…”会列出各段、各轨的特殊方块。可逐项忽略、全选或全部忽略，再次确认后只移除所选方块的外壳。组内音符、`~`、`@`、时长和歌单片段位置保持原样；可一次撤销。

导入时接受 `1<...>` 和 `2<...>`，方块菜单不会提供这两种类型。若 `2<...>` 的总时长不等于最小正常音符，校正器会标黄提示它可能压成一个黑块并打乱节奏；该警告不阻止导出。

### 可视化谱面

在校正窗口点“可视化谱面…”。可按谱段和音轨切换简谱或五线谱，翻页后点选单个音头（包括和弦、琶音和音符组内的音），直接填写音名或升降半音。改时值时可指定用前一项或后一项补偿；总时长和小节线不变。可撤销。两种视图都是便于核对和修改的简化记谱，精确时值见音符下方的 H–P 标记。

MIDI/MusicXML 有调号时按源文件标注，自动跟随全谱移调；段内转调会标出，并能从调号列表跳转。未标注以及导入 JSON 时，按该段音符拟合大调音阶，显示前两个候选和各自的覆盖率。覆盖率表示音高落入该音阶的加权比例，不是统计概率。

可视化窗口支持调整大小，按当前宽度排布每行拍点，每页最多五组谱行。选择“全部音轨”可在共同的时间网格上对齐主旋律和伴奏，仍能单独点选并修改任意音轨的音符。点“从选中处播放”会从所选起音播至全谱结束，自动高亮、翻页和跨段；未选中时从当前页开始。单轨视图可切换是否同时试听其他轨道。

主界面的“重设速度”可输入新的基础 BPM；保留谱面、基础拍长、分段和已配置的梯度。可视化窗口默认显示全部音轨并连续排版，分段点和歌单起止点直接标在谱上。点选音符后可移动已有分段点或设置歌单边界；分段点落在短音符、休止符或音符组内部时会提示。谱面内的分段和歌单改动可以撤销。

主界面的“乐谱无尽段速度计算”按当前普通三段谱面的第三段 BPM 和各段基础拍长推算，无尽第 1 段对应整首第 4 段、循环谱面第 1 段。每段先舍去 BPM 的小数，再用于下一段的计算。窗口显示 BPM、块/s、循环段及倍率，仅用于查看，不写入谱面。

校正器识别发声和后续休止接近等长的疑似跳音。发声音符长于最小正常时值时，可缩短发声并保留总时长；遇到近似等时值的跳音三连音，可合并为 `~`，不会额外保留短休止。MusicXML 中明确标注的跳音连音会在可安全合并时自动转换。选中一个已有方块后，也可用“解散当前音符组”单独移除其外壳，并可撤销。

MusicXML 导入会读取普通音符上的 `staccato` 标记。独立跳音在不改变相邻音符起点的前提下，按当前基础拍长调整发声时值：过长的部分改为休止，过短的从原记谱时值内的休止补足。遇到重叠发音、休止不足、小节线冲突或调整后无法安全分段时，保留原发声写法。MIDI 和已有 JSON 仍通过校正建议处理推测出的跳音。

### 谱面模拟器

主界面和校正编辑器均可打开“谱面模拟器…”。模拟器以四列显示主旋律方块，标出各段边界；鼠标滚轮或滚动条可定位，点选方块可查看对应谱面内容，从当前位置可随系统 MIDI 试听滚动。普通、双黑及狂戳块为黑色，长条和伴奏长条为蓝色，伴奏侧块为浅蓝色，两类滑块为粉色，爆裂块为绿色。左右列布局和折叠滑块走向按模拟规则生成，窗口不修改谱面。

普通块和长条使用四列；紧邻双黑块时避开双黑占用的两列。中间有纯休止时允许复用列，伴奏触发成块的休止仍参与相邻规则。模拟器将异常块涂黄并显示警告标志，点击可查看原因。
